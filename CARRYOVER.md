# Carry-over - keep these in any future redesign

Six things this variant is carrying that are easy to lose in a re-skin.

1. **Images.** All 15 photos are WebP `<img>` with `loading="lazy"`,
   `decoding="async"` and intrinsic `width`/`height`: 7,661 KB -> 1,157 KB
   (-85%), no layout shift. The old animated hero WebP is gone; the hero motion
   is now `ring.js` (14.8 KB of canvas drawing, no dependencies). The 489 KB
   `images/icon.png` header logo is replaced by `images/logo-80.webp` (1.6 KB).
2. **Embeds.** All six embeds (LinkedIn, Spotify, four YouTube) are real
   `<iframe>`s with `loading="lazy"`; each sits in a `<figure>` with an aspect
   box so nothing shifts. Revisit poster facades only if the owner wants them.
3. **Accessibility.** `:focus-visible` outline, `prefers-reduced-motion` (the
   hero draws one static frame and its caption changes wording), real `alt`
   text, `aria-expanded`/`aria-controls` on the menu buttons, Escape closes the
   drawer, skip link to main content, `aria-labelledby` on every section.
4. **Scroll-spy.** IntersectionObserver drives the active nav state - no scroll
   handler. It observes only sections that have a nav entry.
5. **Contrast.** Every text/background pair meets WCAG AA (>= 4.5:1); the
   darkest pair on the page is 8.3:1.
6. **Hygiene.** Strict HTML5 parses with zero errors, viewport allows pinch-zoom
   (no `user-scalable=no`), `theme-color` set to `#0b1526`, Open Graph and
   Twitter card meta, favicon and Apple touch icon, no Font Awesome (inline SVG
   sprite instead), copyright year set by JS with a static fallback.

Plus, specific to this variant: the figure and reference numbering in
`index.html` is generated by `tools/refs.py`. Edit the prose, then run
`python3 tools/refs.py`; `--check` verifies the page is up to date. The output
is committed static HTML - the site has no build step.
